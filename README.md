## Deployment to GitHub Pages
1. Extract all files from `DE_Immaculate_Model_Academy_LMS_Rebuilt.zip`.
2. Upload the extracted files (`index.html`, `styles.css`, `app.js`, `.nojekyll`, `README.md`, and the `assets/` folder) directly into the root of your GitHub repository (`-DE-Immaculate-Model-Academy`).
3. Ensure **GitHub Pages** is enabled under **Settings → Pages → Deploy from a branch (`main` / `root`)**.
